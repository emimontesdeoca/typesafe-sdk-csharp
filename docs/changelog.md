# Changelog

## 0.6.0 - 2026-09-18

- Added the `TypeSafe.Ai` package for .NET 10.
- Preserved the v0.6.0 score rubric as an ordered list of descriptions.
- Preserved buffered raw responses, per-attempt timeout classification, retry headers, and source
  snake-case JSON names.
- C# uses runtime answer dictionaries and caller-defined DTOs instead of TypeScript literal-key
  inference.

## Source provenance

The JavaScript SDK history represented by this port includes the v0.6.0 score-rubric change and the
v0.5.7 initial public release.
